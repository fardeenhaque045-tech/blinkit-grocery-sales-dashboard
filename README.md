# BlinkIT Grocery Sales Analysis Dashboard

## Project Description

This project focuses on analyzing BlinkIT grocery sales data using Tableau to understand sales performance, product categories, outlet characteristics, and customer ratings.

The interactive dashboard presents key performance indicators (KPIs), including Total Sales, Average Rating, Average Item Weight, and Sales per Outlet. It also visualizes sales by Item Type, Outlet Type, Outlet Size, and Outlet Location Type.

Interactive filters allow users to explore the data and compare sales performance across different product categories and outlet characteristics. The project demonstrates data visualization, calculated fields, KPI development, dashboard design, and interactive filtering in Tableau.

## Project Objectives
- Analyze overall grocery sales performance.
- Identify product categories contributing to sales.
- Compare sales across different outlet types and sizes.
- Examine outlet location and sales patterns.
- Present important business metrics through an interactive dashboard.

## Tools Used
- Tableau
- BlinkIT Grocery Data
- Calculated Fields and KPI Cards
- Interactive Filters and Data Visualization

## Key Outcome

Developed an interactive Tableau dashboard that transforms grocery sales data into visual insights, helping users explore sales performance and compare different product and outlet segments..
